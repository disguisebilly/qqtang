# AI糖泡装扮ID对照表

在`configs/server-directory-local-ui.json`的`competitive_ai.bubble_costume_item_ids`数组中填写下表的物品ID。下表包含当前客户端全部295种特殊糖泡；ID与名称来自物品目录，不能用资源编号代替。

- `[119, 256, 257]`：只从星光、草莓、西瓜糖泡中随机选择。
- `[]`：不使用特殊糖泡，使用普通默认糖泡，也不附加锻造颜色或特效。
- 发布默认配置的三个数组均为`[0]`：普通默认泡、无颜色、无特效；未填写数组、`null`或`[]`也表示该项不启用。
- 糖泡数组也支持0，表示普通默认泡。例如`[0,119]`会在普通默认泡与星光糖泡之间随机选择；0是配置选项，不是需要装备的物品ID。
- 另两个数组为`bubble_costume_color_ids`和`bubble_costume_effect_levels`。颜色0为无染色、1黑、2蓝、3红、4绿、5紫；等级0为无特效，1～5为特效等级。
- 颜色或等级数组可包含0，0也参与随机抽取；也可省略数组或设为`[]`。无颜色时自动不附加特效，另一个数组不必清空；等级数组为空只取消特效。普通默认泡不附加颜色或特效。
- 保存配置后重启服务端生效。三个数组的完整示例和抽取规则见[AI糖泡外观说明](avatar-forge-rules.md)。
